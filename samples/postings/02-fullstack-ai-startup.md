- Ship product features across our Next.js frontend and Python backend.

- TypeScript and React.
- Python (FastAPI or Django).
- Hands-on experience with LLM APIs (OpenAI, Anthropic or similar).
- PostgreSQL.
- Comfortable working in a fast-moving startup with high ownership.

## Bonus points
- Experience with vector databases or pgvector.
- Built evaluation pipelines for ML or LLM features.
- German language skills.

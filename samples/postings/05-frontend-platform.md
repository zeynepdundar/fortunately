# Frontend Platform Engineer — Orbitly (fictional)

Orbitly is a travel-planning platform with 2 million monthly users. Amsterdam or remote (Netherlands).

## About the team
The Frontend Platform team owns build tooling, CI, performance budgets and shared libraries for 40 engineers.

## Requirements
- 5+ years of experience with JavaScript and TypeScript.
- Strong knowledge of build tools (Vite, webpack or Turbopack).
- Experience with monorepos (Nx, Turborepo or pnpm workspaces).
- CI/CD with GitHub Actions.
- Web performance: Core Web Vitals, bundle analysis.
- React.

## Nice to have
- Micro frontends or module federation.
- Experience with Kubernetes or Docker.
- Public speaking or writing about frontend topics.
